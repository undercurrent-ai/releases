Lair

A project tracker that runs on your own machine

Epics, stories, bugs and tech debt across every project, in a board that opens instantly and works with no network.

There is no server and no account. The whole database is one SQLite file in your home directory, which means it is yours, it is greppable, and backing it up is copying a file.

Four themes including a sepia reading mode, tight 2–6dp corners, and a high-contrast vibe for when the room is bright.

Lair 2.0.1 — the first build published to the release channel.

Until now Lair was installed by a script that overwrote /Applications/Lair.app on the machine it was built on. This is the same app, packaged so it can be handed to somebody else and kept current by Depot.

Installing

  • Unzip and drag to Applications, or let [Depot](../depot/) do it — Depot

replaces the bundle atomically and quits a running copy first, which a manual drag does not.

  • Your board lives in ~/.undercurrent/lair/db/lair.db and is untouched by an

update. It is one SQLite file: copying it is a backup.

First launch

This build is ad-hoc signed rather than notarised, so macOS asks once. Open System Settings → Privacy & Security and click Open Anyway. Installing through Depot skips this entirely — a Depot install carries no quarantine flag.

Note on size

180 MB unpacked. Lair is a Compose Desktop app and ships its own Java runtime, so the download is what it is. Nothing is downloaded at first run.
