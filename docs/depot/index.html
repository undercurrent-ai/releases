Depot

The storefront and updater for everything here

Depot lists everything on this channel, installs it, and tells you when a newer version exists.

On Android it is the reason updates work at all: an APK installed by hand from a web page has nothing that ever checks for a successor, so Depot does the checking — once a day, in the background, with a notification naming what is behind. Nothing installs without you tapping it; no third-party store on Android can install silently, and one that claimed to would be lying.

On macOS it installs apps that have no updater of their own and updates the ones that do. It replaces a bundle atomically, so a crash halfway through cannot leave an app that will not start, and because Depot is not a browser the apps it installs carry no quarantine flag — the Gatekeeper prompt you get from a download never appears.

Every download is checked against its published SHA-256 and an Ed25519 signature from the release key before anything is installed. The public half of that key is compiled into Depot, so write access to the public release repository is not enough to push code to anybody.

macOS

  • Lists every product the channel publishes for macOS, with what you have

installed next to what is available.

  • Installs and updates apps that have no updater of their own. The bundle is

replaced atomically, so a crash halfway through cannot leave an app that will not start, and a running copy is quit first rather than having its files pulled out from under it.

  • Apps it installs carry no quarantine flag, because Depot is not a browser.

The Gatekeeper prompt you meet once on a downloaded app never appears for anything installed this way.

  • Writes to /Applications when that is writable by your account, which it is on

a stock macOS, and falls back to ~/Applications. It never asks for an administrator password: an installer that can elevate is a much larger thing to trust than one that cannot.

What is verified before anything is installed

  • The download's SHA-256 against the published manifest.
  • An Ed25519 channel signature over

<product>\n<platform>\n<version>\n<file>\n<sha256>\n, checked against a public key compiled into Depot. Write access to this public repository is therefore not enough to install code on anybody's machine.

  • The version is inside the signed bytes, so a valid old signature cannot be

replayed to force a downgrade; the filename is inside them too, so a signature covering one artefact cannot be presented alongside another from the same release.

Known limits in 0.1.0

  • Depot does not update itself yet. It would have to quit itself mid-install, and

doing that correctly needs a helper process. Rebuild it from source, or download it from the store page.

  • Android is a separate build, not in this release.
First launch. These builds are ad-hoc signed, so macOS asks once. The one-time steps are here — later updates are installed by the app itself and never hit that prompt.
