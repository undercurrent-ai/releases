Tunnel Bore

Hand long jobs to a machine that never sleeps, without being rude about it

A laptop is the wrong place to run something that takes four hours. Tunnel Bore joins a roaming Mac to an always-on machine over a self-hosted WireGuard overlay, and gives you a queue there that does not care whether the lid is open.

bore push hands a job to the node. bore status is the fleet on one screen, cached so it still tells you something when the node is unreachable. bore drain says you are going offline on purpose, which is different from having vanished. bore doctor says what is wired and what is not, in the order you should fix it.

The borrowed-machine part is the point. The always-on node is often a household PC somebody else games on. A courtesy warden watches for that and yields — the queue pauses itself rather than competing for a GPU, and resumes when the machine is idle again. It detects rather than asks, because a tool that needs permission every time gets turned off.

Secrets never rest on the node. Anything stored there is sealed to a public key whose private half stays in the Mac's keychain, so a node that is lost or reinstalled leaks nothing. The node kit ships the WireGuard generator, the sealed vault and the setup steps for both Linux and Windows.
