BreachRadar

Breach monitoring and an outreach queue, on your own machine

Watches SEC EDGAR 8-K Item 1.05 filings and six incident-press feeds, and puts every new disclosure in front of you as a triage queue rather than a dashboard you have to remember to open.

Eight columns from Inbox to Call booked. The day counter on each card is computed as it renders, so a target sitting in Hold turns colour by itself on the morning it enters the window you care about. Nothing is auto-filed into an outbound column — extracting an organisation from a headline is a heuristic and it is wrong often enough to matter.

No daemon, no API keys, no telemetry and no server. It polls when you open it, or once a day at most. Your board, notes and settings stay in a folder in your home directory and an update never touches them.

The first release built to be handed to other people rather than run only on the machine it was written on.

Installing

  • Compressed .dmg (~690 KB) with an Applications drop target, a `READ ME

FIRST covering the first-launch Gatekeeper prompt, and a First Run.command` that clears the quarantine flag for you.

Updating

  • Settings → General → Check now, or ⌘-menu → *Check for Updates…*, plus a

quiet once-a-day check on launch that says nothing unless there is news.

  • An update is downloaded from this repository's releases and is **refused

unless it carries a valid Ed25519 signature** from the release key. The signed message includes the version, so an old signature cannot be replayed to force a downgrade. The swap is atomic — a crash mid-update cannot leave an app that will not start.

  • Your board, notes and settings live in ~/.undercurrent/breachradar/ and are

untouched by an update.

Privacy

  • The SEC contact address is a preference now instead of a value baked into the

binary. Set yours in Settings → General; Settings also shows exactly what the app sends. Nothing else about you leaves the machine — there is no server and no telemetry.

  • Paths that assumed a ~/NEXUS tree fall back to the app's own store, so a

fresh install creates nothing in a stranger's home directory.

  • The build refuses to finish if any machine-identifying string is found inside

the bundle.

Fixed

  • Update checks bypass the URL cache. Without this the appcast and the zip could

both be answered from cache, which looks like a working updater right up until a release goes out and nobody is offered it.

First launch. These builds are ad-hoc signed, so macOS asks once. The one-time steps are here — later updates are installed by the app itself and never hit that prompt.
