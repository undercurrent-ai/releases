Installing on macOS

These builds are signed, but with an ad-hoc signature rather than a paid Apple Developer ID. macOS therefore asks about the first launch. It asks once, per app, ever.

First launch

  1. Open the .dmg and drag the app to Applications.
  2. Launch it. macOS says it "cannot be opened because Apple cannot check it for malicious software".
  3. Open System Settings → Privacy & Security, scroll to the bottom, and click Open Anyway next to the app's name.
  4. Launch it again and confirm. That is the last time you will see this.
macOS 15 removed the right-click → Open shortcut that used to skip step 3. Guides that still tell you to right-click are out of date. Each DMG also carries a First Run.command that clears the quarantine flag for you if you prefer that.

Updates never ask again

An app updating itself from this channel replaces its own bundle in place. There is no download from a browser, so no quarantine flag, so no Gatekeeper prompt. The one-time approval above is genuinely one time.

What an update checks

  • The manifest's Ed25519 signature against the public key compiled into the app itself.
  • The downloaded zip's SHA-256 against the signed manifest.
  • The signed bytes include the version, so a valid old signature cannot be replayed to push you a downgrade.

The swap is atomic: a crash mid-update cannot leave an app that will not start.

Verifying a download yourself

shasum -a 256 ~/Downloads/TheApp-1.0.0.dmg

Compare against the SHA-256 on the app's page. Those are published from the same build that produced the file, and a published version is never rebuilt.
