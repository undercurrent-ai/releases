Depot for Android

Android has no notion of a second app store, so updates need something that checks for them. Depot is that: one app that lists everything on this channel, installs it, and tells you when a new version appears.

1 · Install Depot

Not published yet. Depot for Android is built but has no release on the channel yet. Until it does, install each APK from its own product page by hand.
Android will ask permission twice, and that is normal. Once to allow your browser to install an APK at all (Settings → Apps → Special access → Install unknown apps), and once per install to confirm. Depot cannot install anything silently — no third-party store can, unless it ships with the device.

2 · Everything else comes from Depot

Open it and the catalogue is there. It checks once a day in the background and posts a notification when something is newer than what you have installed. Nothing is installed without you tapping it.

Installing by hand instead

Every APK is on its product page with its SHA-256. That works fine — you just won't hear about updates. To check a download before installing:

sha256sum MyApp-1.0.0.apk   # or: shasum -a 256 on macOS

What Depot verifies before it installs

  • The download's SHA-256 matches the manifest.
  • The manifest carries a valid Ed25519 signature from our release key. Write access to the public channel repo is not enough to push an app to anybody.
  • The APK's own signing certificate matches the one the manifest pins — so a swapped file is refused by Depot, rather than by a system dialog you'd read as "this app is broken".
